# Registros de decisão arquitetural

Estes ADRs são normas do projeto. O código, os testes, o OpenAPI e os notebooks devem
permanecer coerentes com as decisões aceitas abaixo.

| ADR | Decisão | Estado |
|---|---|---|
| [0001](0001-evidencia-e-artefatos-fail-closed.md) | Evidência científica e artefatos por identidade criptográfica | Aceita |
| [0002](0002-identidade-atomicidade-e-historico-limitado.md) | Identidade estável, mutações atômicas e leituras limitadas | Aceita |
| [0003](0003-openapi-como-contrato-executavel.md) | OpenAPI ao vivo como contrato executável canônico | Aceita |
| [0004](0004-perfil-publico-proxy-auth-tls-rate-limit.md) | Perfil público com proxy, TLS, OIDC e limites fail-closed | Aceita; homologação externa pendente |
| [0005](0005-promocao-cientifica-de-modelos-fail-closed.md) | Promoção de visão condicionada a holdout externo e receipt reproduzível | Aceita; nenhum modelo atual promovido |
| [0006](0006-distribuicao-canonica-unica.md) | Uma única distribuição canônica em monólito modular | Aceita |
| [0007](0007-autorizacao-visual-apenas-com-evidencia-externa.md) | Somente F2 externamente validado autoriza decisão | Aceita; F1/VLM são diagnósticos |
